# legacy

Старая версия генератора: `char_generator_32x48.py` (из BlockBrawler/tools/gen_fighters.py).

Кадр **32x48**, вид силуэтом сбоку: тёмный корпус, неоновый контур, плоская
заливка. Три персонажа: `tetrax`, `matrix`, `overlord`. Лист 4x6, та же сетка
анимаций (idle / punch / kick / super / stun / slip).

Оставлено для справки: здесь видно, как выглядели позы до перехода на
материалы и объём. Новым персонажам сюда идти не стоит — актуальный генератор
в корне проекта (`char_generator.py`), он в 4 раза крупнее и рисует объём.

Запуск (для сравнения):

```bat
py char_generator_32x48.py
```
